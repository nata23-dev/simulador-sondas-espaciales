                      Spacecraft Ephemeris File Release
  
Spacecraft Ephemeris: SAT337
 
Location: ssd.jpl.nasa.gov/pub/eph/spacecraft/vgr1.sat337.nio

Timespan from JED 2444458.50(07-AUG-1980) to JED 2444563.50(20-NOV-1980)
Equinox Reference Julian Date: 2451545.00
Planetary Ephemeris Number: DE-0421/LE-0421

Release to: Horizons/NAIF                      Time: 13-Feb-2012 00:00:00
Preparer: R. A. Jacobson

Comments:
Smoothed Voyager 1 trajectory for the Saturn encounter consistent with the
SAT337 planetary ephemeris and the SAT337 satellite ephemeris.  This file
was created from a fit to the Voyager Doppler, range, optical, and Saturn ring
occultation data.  It is determined together with the planet and satellite
ephemerides as part of the Global Saturnian System Analysis.  The two
references discuss earlier results produced by that analysis. The SAT337
analysis includes Cassini data through September 2010 (the end of the Cassini\
Equinox Mission).
