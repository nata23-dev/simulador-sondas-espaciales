This "final" reconstructed trajectory for the Voyager 1 spacecraft
at Saturn replaces the file "vg1_sat" produced by NAIF in August of
1980 using a set of near-real time OD solutions produced by the
Voyager NAV Team for use in SEDR production and other engineering
activities.

NAIF's "CMPSPK" (Compare SPK) program was run onthese two files to
produce a statistical comparison. This produces a lengthy report,
but the summary of this comparison is as follows:

 generated for the test case that had the largest relative difference
